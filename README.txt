CONTROLE DE CASAS DE APOSTAS POR CPF

FUNÇÕES
- Cadastro de vários CPFs.
- Cadastro de várias casas de apostas em cada CPF.
- Alteração do valor atual de cada conta.
- Total por CPF e total geral.
- Pesquisa por nome, CPF ou casa.
- Backup e restauração em arquivo JSON.
- Salvamento automático no navegador.
- Tema claro e escuro.
- Pode ser instalado como aplicativo no celular após publicação.

COMO TESTAR NO COMPUTADOR
1. Extraia o arquivo ZIP.
2. Abra a pasta.
3. Dê dois cliques no arquivo index.html.

COMO PUBLICAR GRATUITAMENTE NO GITHUB PAGES
1. Entre no GitHub.
2. Crie um repositório novo.
3. Envie todos os arquivos desta pasta.
4. Abra Settings > Pages.
5. Em Source, selecione Deploy from a branch.
6. Selecione a branch main e a pasta /root.
7. Salve.
8. O GitHub mostrará o endereço do aplicativo.

COMO INSTALAR NO CELULAR
1. Abra o endereço publicado no Google Chrome.
2. Toque nos três pontos.
3. Toque em “Adicionar à tela inicial” ou “Instalar aplicativo”.

IMPORTANTE
Os dados são armazenados no navegador do aparelho. Limpar os dados do navegador
pode apagar os registros. Use regularmente o botão “Exportar backup”.
Não armazene senhas das casas de apostas neste programa.
